# 회의노트 (개인용 안드로이드 앱)

갤럭시 폴드6에서 쓰는 회의록 앱입니다. API 요금 없이 **삼성 음성 녹음(Galaxy AI 텍스트 변환) + Claude 프로젝트(구독)** 조합으로 동작합니다.

## 흐름
1. 삼성 **음성 녹음** 앱으로 회의 녹음 → 녹음 파일에서 **텍스트 변환** 실행
2. 변환된 텍스트를 **공유 → 회의노트**
3. 회의노트에서 **Claude로 보내기** → Claude 앱에서 `회의록 정리` 프로젝트 선택 → 붙여넣기(요청 문구 자동 복사됨) → 전송
4. Claude 답변의 **공유** 버튼 또는 받은 `.md` 파일을 **공유 → 회의노트**
   - 정리본 첫 줄의 `회의ID`로 원래 회의에 자동 연결
   - `내 파일 › 다운로드 › 회의노트` 폴더에 `.md`로 자동 저장
5. **Gmail로 보내기**(저장한 받는 사람 선택) / **다음 일정 캘린더에** 추가

모든 데이터는 폰 안(앱 저장소 + 다운로드 폴더)에만 저장됩니다.

## Claude 프로젝트 만들기 (처음 한 번)
앱 오른쪽 위 `?` 버튼 → **지침 복사** → Claude에서 새 프로젝트 `회의록 정리`를 만들고 지침(Instructions)에 붙여넣기.
지침 원문은 `app/src/main/java/com/kakajeje/meetingnotes/ClaudeGuide.kt`에 있습니다.

## 설치
1. GitHub → 이 저장소 → **Actions** → `Meeting Notes APK` → 최신 실행 → **Artifacts**의 `meeting-notes-apk` 다운로드
2. 압축을 풀어 나온 `app-debug.apk`를 폰에서 열기 → "출처를 알 수 없는 앱 설치" 허용 → 설치
3. 업데이트도 같은 방법으로 덮어 설치하면 됩니다(같은 서명 키 사용).
